Republic Mod Manager - manual installation
==========================================

Requirement: the TesmioLoader by MaxLegend (b0.4.6 or newer) is installed, so
the game folder already has the folder tesmioloader with tesmioloader.dll,
tesmiolauncher.exe and tesmioloader.ini. Nothing works without it. The
tesmioloader.dll in this folder is a corrected build of his b0.4.6
(b0.4.6-rmm.1, same API) and replaces the one you have - keep a copy of the
old one if you want a way back.

1. Close the game, the TesmioLauncher and Republic Mod Manager.

2. Drag the folder "tesmioloader" (next to this file) onto the game folder:
      C:\Program Files (x86)\Steam\steamapps\common\SovietRepublic
   Windows asks "Merge folders?" - Yes. Existing files may be overwritten;
   your settings are in user_config and in plugins and are not touched. Only
   an rmm.ini of your own should be saved first.

   Afterwards you have:
      tesmioloader\tesmioloader.dll              the loader (corrected build b0.4.6-rmm.1)
      tesmioloader\rmm.exe                       the manager
      tesmioloader\rmm.ini                       its base settings
      tesmioloader\rmm.README_DE.md / _EN.md     guide (German / English)
      tesmioloader\rmm.SCHEMA_DE.md / _EN.md     reference for plugin authors
      tesmioloader\settings_schemas\             settings pages of the plugins
      tesmioloader\languages\                    the window in 18 more languages

3. Start rmm.exe. Done.

You do not have to copy Resources Plus, Needs Plus and Buildings Plus: they
lie in the folder "plugins" of this Workshop item, and the TesmioLoader loads
them from there while you are subscribed. If buildings_plus.dll,
resources_plus.dll, needs_plus.dll or workshop_bridge.dll from an earlier
installation still lie in tesmioloader\plugins, delete these four files -
otherwise the loader loads the old copies instead of the current ones. The
files resources_plus.ini, needs_plus.ini and buildings_plus.ini there are
your lists and stay.

Removal: delete the files named above (tesmioloader.dll only when you copy
the old one back). The folders user_config and plugins with your settings
can stay.
